# NLP-based-Intent-Classification-System
This project implements an NLP and machine learning–based intent classification system that analyzes customer support messages and categorizes them into predefined intents. It serves as the core decision-making component of an e-commerce customer support chatbot.
Supported Intents

Track Order

Cancel Order

Refund Status

Delivery Delay

Payment Issue

# Methodology

Text preprocessing using NLP techniques (NLTK)

Feature extraction with TF-IDF

Multi-class classification using machine learning models

Real-time intent prediction via Streamlit UI

# Tech Stack

Python, Pandas, NLTK, Scikit-learn, Streamlit, Joblib
